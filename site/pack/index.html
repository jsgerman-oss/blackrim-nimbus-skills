Hosting pack

Scaffold an app. Deploy it. One golden path.

nimbus is the city-side GasCity pack that makes a town app-hosting capable. An agent scaffolds a new web app on the golden path and deploys it end to end, then reaches for any of the 19 clouds when the job calls for it. Stdlib-only Python: no overlay, no hooks, no prompt fragments.

The golden path

vite, voidzero, Cloudflare, Convex.

The build chain, the deploy target, and the data layer, chosen so they fit together without configuration. One command per step, typed end to end.

01

Vite

Scaffold

npm create vite. Instant dev server, first-class TypeScript, the front door to the toolchain.

02

voidzero

Build

Vite, Rolldown, and Oxc: one Rust-grade toolchain that lints, bundles, and tests.

03

Cloudflare

Deploy

wrangler deploy ships to Workers and Pages at the edge, global by default.

04

Convex

Data

convex deploy gives you a reactive, typed backend: queries, mutations, live state.

What it provides

A small, runnable enabler.

The pack is the runnable companion to the 19 per-provider plugins. Those teach Claude each cloud's well-architected defaults; the pack turns that into a golden path plus breadth across all 19 clouds.

PathRole
bin/nimbusThe app-scaffold and deploy CLI.
nimbus/The engine, pure standard library.
skills/golden-path-hosting/The golden-path deploy skill.
docs/DESIGN.mdThe pack's design and scope.

Stdlib-only, on tomllib with a tomli fallback. It mirrors the minimal footprint of gascity-cockpit and provider-forge.

quickstart
# build the engine venv (optional)
./setup.sh

# what is this pack, what lands where?
./bin/nimbus info

# version, text or JSON
./bin/nimbus version --json

The scaffold CLI ships version and info today. Scaffold a new app on the golden path and deploy it to one of 19 clouds lands next.

Install into a city

Vendor it, register it, reload.

Drop pack/ into the target city as packs/nimbus/, then install at town or rig scope. It registers a direct source = "packs/nimbus" import (the gastown pattern), runs gc reload, and verifies.

packs/nimbus
# city-wide
packs/nimbus/install.sh --town

# one rig
packs/nimbus/install.sh --rig <name>

# preview without writing
packs/nimbus/install.sh --town --dry-run

# reverse it (--purge to drop the venv)
packs/nimbus/uninstall.sh --town
