The golden path

One opinionated path, four moving parts.

Breadth is the option set; the golden path is the default. Scaffold with Vite, build with the voidzero toolchain, deploy to Cloudflare at the edge, and back it with Convex. Four steps, typed end to end, live in seconds.

01

Vite

Scaffold

npm create vite. Instant dev server, first-class TypeScript, the front door to the toolchain.

02

voidzero

Build

Vite, Rolldown, and Oxc: one Rust-grade toolchain that lints, bundles, and tests.

03

Cloudflare

Deploy

wrangler deploy ships to Workers and Pages at the edge, global by default.

04

Convex

Data

convex deploy gives you a reactive, typed backend: queries, mutations, live state.

What ships per cloud

Nineteen plugins, one canonical shape.

Every toolkit follows the same structure, enforced by CI and validated by schema. Learn one, and the next eighteen feel identical. Switching clouds never breaks your muscle memory.

6 per cloud

Domain skills

Auto-fire by description match. They cover compute, storage and databases, networking and edge, identity and security, IaC and deployment, observability and cost.

2 per cloud

SME sub-agents

A <provider>-architect for well-architected review and a <provider>-security-reviewer for audits, scoped to that cloud's services.

1 or more

Slash commands

/<provider>-scaffold-iac and platform-specific scaffolds that turn a one-line request into infrastructure with the right defaults.

Defaults are not generic. Each plugin bakes in encryption at rest, least-privilege identity, private-by-default networking, observability before launch, and cost flagged at decision time.

Breadth

Every major cloud, one muscle memory.

Hyperscalers, edge platforms, app platforms, and the regional clouds. Cloudflare is lit as the golden-path target; the rest sit available, one hover away.

Hosting pack

Scaffold an app. Deploy it. Repeat.

nimbus is the city-side GasCity pack that makes a town app-hosting capable. An agent scaffolds a new web app on the golden path and deploys it to any of the 19 clouds. Stdlib-only Python, no overlay, no hooks.

Read the pack
nimbus
# scaffold a new app on the golden path
nimbus new app --golden-path

# deploy it, edge-first
nimbus deploy --to cloudflare

# or pick any of the 19 clouds
nimbus deploy --to fly
